## Итоговый проект

В качестве итоговой работы используется разработанный в рамках курса **GeoAnalytics Service**:

- веб-интерфейс на **Streamlit**;
- получение объектов городской инфраструктуры из **OpenStreetMap**;
- обработка пространственных данных средствами **GeoPandas** и **Shapely**;
- формирование гексагональной сетки **H3**;
- расчёт показателей доступности и обеспеченности;
- нормализация и объединение показателей;
- интерактивная картографическая визуализация;
- экспорт результатов в **GeoJSON**.

Каждый обучающийся выбирает собственную территорию и прикладную задачу, после чего:

1. определяет набор анализируемых пространственных объектов;
2. настраивает OSM-теги в `tags_presets.json`;
3. задаёт и обосновывает радиусы доступности;
4. задаёт веса показателей;
5. выполняет пространственный анализ;
6. получает и анализирует итоговую карту;
7. интерпретирует результаты с точки зрения архитектуры, градостроительства, картографии или геоинформатики;
8. предлагает возможные решения по результатам анализа исследуемой территории.
